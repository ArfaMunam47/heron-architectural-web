## 👀 The Concept

What happens when you take an award-winning digital experience and challenge yourself to recreate its visual language?

**Architectural Web Experience** is a frontend practice project inspired by **HERON.W**, an Awwwards Site of the Week recognition recipient. The project explores the intersection of architectural aesthetics, editorial design, precision layouts, and interactive web experiences.

This is more than an attempt to reproduce a beautiful interface. It is an opportunity to study the decisions behind exceptional UI design, experiment with creative implementation techniques, and push my frontend skills beyond conventional layouts.

> *Good design catches your attention. Great interaction makes you remember it.*

## 🎯 Why I Am Building This

I believe that becoming a better frontend developer requires more than learning syntax or building standard landing pages.

I want to understand how exceptional websites use spacing, typography, composition, movement, and interaction to create a complete digital experience.

Through this project, I am working to:

- 🎨 Improve my UI design sense and visual accuracy.
- 🧩 Recreate complex layouts with precision and consistency.
- 🎬 Explore smooth transitions, scroll-based reveals, and motion design.
- 🏛️ Experiment with architectural illustrations and editorial compositions.
- ⚡ Push my creative boundaries through advanced vibe coding.
- 🛠️ Strengthen my practical frontend implementation and debugging skills.
- 📱 Learn to preserve visual quality across desktop, tablet, and mobile screens.

**The goal:** turn inspiration into hands-on learning and creativity into working interfaces.

## ✨ Design Direction

The experience takes cues from architectural publications, technical drawings, and carefully art-directed digital studios.

| Element | Design approach |
| --- | --- |
| 🎨 Visual identity | Warm ivory, near-black, and vermilion accents |
| 📐 Layout | Precision grids, fine borders, and asymmetric compositions |
| 🔠 Typography | Bold editorial headlines and compact technical labels |
| 🏛️ Imagery | Architectural illustrations and monochrome visuals |
| 🎬 Motion | Restrained reveals, transitions, and interactive details |
| 🖱️ Interaction | Intentional hover states and responsive interface feedback |

Every detail is an opportunity to understand why a design works, how it is constructed, and how it can be translated into a functional frontend.

## 🧪 What I Am Exploring

**01 — UI Recreation**

Studying the reference and translating its visual structure into a carefully composed, responsive interface.

**02 — Motion & Interaction**

Exploring animation timing, scroll-triggered effects, image reveals, and subtle interaction states.

**03 — Advanced Vibe Coding**

Using AI-assisted development as a creative workflow while refining prompts, evaluating generated code, and iterating on the actual results.

**04 — Visual Precision**

Learning to identify and correct inconsistencies in spacing, alignment, typography, proportions, and component behavior.

**05 — Frontend Craft**

Practicing component-based architecture, reusable styling, responsive layouts, and maintainable implementation.

## 🛠️ Development Approach

This project uses an AI-assisted, iterative workflow.

- **Design reference:** HERON.W
- **Development environment:** Lovable
- **Core focus:** Frontend UI, layout, and interaction
- **Workflow:** Analyze → Build → Compare → Refine
- **Priority:** Visual fidelity, usability, and creative execution

The implementation and technology choices may evolve as the project develops.
